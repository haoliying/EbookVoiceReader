# 朗读时光 · EbookVoiceReader

一款完全离线的 Android 电子书朗读应用。内置语音合成引擎与中英文发音模型，不依赖手机系统 TTS，也不会上传任何书籍内容。

## 功能

- 支持 TXT、Markdown、PDF、DOCX、EPUB 电子书
- 支持图片与扫描版 PDF 的离线 OCR 文字识别
- 内置 sherpa-onnx 语音引擎，自带中英文声音
- 中英文混读，英文按完整单词朗读，不会逐字母拼读
- 朗读时高亮当前段落并自动滚动
- 播放 / 暂停 / 停止、上一段 / 下一段、0.5x–2.0x 语速

## 语音模式

点击底部「语音模式」切换：

| 模式 | 说明 |
| --- | --- |
| 中英混读（默认） | 中英文由同一个双语女声朗读，英文按单词发音 |
| 中文女声 | 中文使用「小雅」音色，遇到英文单词自动改用双语声 |

切换模式时若正在朗读，会从当前段落用新音色继续。

## 操作手册

1. **打开书籍**：点击右上角「选择文件」，或在文件管理器里用「其他应用打开」选择「朗读时光」。
2. **开始朗读**：点击底部中央圆形按钮开始，再次点击暂停；右侧方形按钮停止并回到开头。
3. **切换语音模式**：点击底部「语音模式」选择「中英混读」或「中文女声」。
4. **调整语速**：拖动「语速」滑块，0.5x–2.0x 实时生效。
5. **切换段落**：点「上一段 / 下一段」跳转，暂停时也会高亮目标段落。
6. **图片 / 扫描版 PDF**：会先做离线 OCR，页数较多时需要等待几秒。
7. **没有声音**：先检查媒体音量是否为 0；若提示「语音引擎加载失败」，请确认安装包完整或重新安装。
8. **完全离线**：语音引擎、发音模型与 OCR 模型均内置在 APK 中。

## 构建

```bash
# 双语语音模型超过 GitHub 单文件限制，需先下载
./scripts/fetch-tts-model.sh
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`

需要 JDK 17、Android SDK 34。sherpa-onnx 以本地 AAR 形式放在 `app/libs/`。

## 开源组件与许可

- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)：Apache-2.0
- vits-piper-zh_CN-xiao_ya-medium-int8：仅限非商业使用
- [vits-melo-tts-zh_en](https://github.com/myshell-ai/MeloTTS)：MIT
- ML Kit 文字识别、PdfBox-Android、Jsoup

由于「小雅」音色仅限非商业用途，本项目仅供个人学习与非商业使用；商用请替换为 Apache-2.0 许可的模型。
